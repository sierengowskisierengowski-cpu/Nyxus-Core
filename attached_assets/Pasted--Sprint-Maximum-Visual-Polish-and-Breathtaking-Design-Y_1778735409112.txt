
"Sprint — Maximum Visual Polish and Breathtaking Design
You already know the brand. You already know the colors, fonts, and aesthetic. This sprint is about taking everything already built and pushing it to the absolute maximum visual level. Not normal Linux. Not plain. Not boring. Breathtaking. The kind of desktop that makes someone stop and say wow the second they see it. Every detail intentional. Every interaction satisfying. Every element stunning.
Animations — everything must move beautifully:
Every window that opens must animate in — not just appear. Fade in, scale up slightly, ease into place. Every window that closes fades and scales down. Every app launch has a smooth entrance animation. Workspace switching has a fluid slide or fade transition — not a hard cut. Every toggle slides smoothly. Every dropdown cascades open. Every notification slides in from the edge and fades out elegantly. Every button has a subtle press animation — it depresses slightly when clicked and springs back. Every interactive element responds to hover with a subtle glow or highlight. Nothing in the entire OS is static and dead — everything breathes and responds.
Glassmorphism — push it to the maximum:
Every panel, every flyout, every overlay, every widget must have deep frosted glass blur behind it. Layered transparency — closer elements more opaque, background elements more transparent. The bar should feel like it's floating above the wallpaper. Quick settings flyout should look like frosted glass hovering in the air. Notification center should have depth. Every dialog box should feel like it's made of dark glass. The SDDM login panel should be a stunning frosted glass card centered on a breathtaking background. Push the blur depth, push the transparency, push the layering until it looks like nothing else on Linux.
Glow and light:
Subtle glow on every active element in the current theme pack accent color. Window borders glow softly when focused, dim when unfocused. Active workspace indicator in the bar glows. Buttons glow on hover. The dock items glow on hover and when the app is running. The cursor leaves a subtle trail or glow as it moves. Every accent element has a soft light source behind it. The whole desktop should feel like it's lit from within.
Micro interactions — every detail matters:
Clicking anywhere on the desktop produces a subtle ripple effect. Toggling a switch has satisfying momentum — it slides and bounces slightly into place. Sliders have inertia — they feel weighted. Dragging a window feels smooth with slight resistance. Minimizing a window has a genie-style animation shrinking into the taskbar. Maximizing scales up smoothly. Closing has a quick fade and scale down. Notifications group with a smooth stack animation. The clipboard overlay appears with a spring animation. Every single interaction in the entire OS must feel considered and satisfying.
SDDM login screen — make it stunning:
This is the first thing anyone sees. It must be breathtaking. Full animated or deeply atmospheric background. The login panel is a stunning frosted glass card, perfectly centered, with subtle glow around the edges. The NYXUS logo or owl mascot above the input field. Clock and date displayed elegantly above the panel. Input field has smooth focus animation — the border lights up in the accent color when clicked. The login button has a satisfying press animation. Subtle floating particles or animated elements in the background. This must be the most beautiful login screen on any Linux distribution.
Plymouth boot splash — cinematic:
Pure black background. The NYXUS owl mascot or logo animates in from nothing — materializes with a glow effect. A subtle particle or light effect around it. A slim progress bar at the bottom in the accent color. The whole thing feels like the opening of a premium product. Smooth, dark, cinematic. Not a spinner on a grey background.
The bar — floating and premium:
The bar must look like it is floating above the wallpaper, not stuck to the edge. Rounded corners on the bar itself. Deep blur behind it. Clock centered and elegant. Workspace indicators are glowing dots or pills that pulse when active. System tray icons perfectly spaced. The whole bar feels lightweight and premium — like it belongs on a thousand dollar device.
Wallpaper integration:
The desktop color scheme should subtly respond to the wallpaper. If the wallpaper is dark the panels stay dark. Accent glow colors pick up hints from the wallpaper palette while staying within the brand. The wallpaper itself should feel alive — if animated wallpapers are active they should be smooth and atmospheric, not distracting.
Icons and cursor:
Every icon in the NYXUS Dark set must be crisp, consistent, and beautiful at every size. The NYXUS Aurora cursor must feel premium — smooth, correctly sized, with a subtle glow on the pointer tip. The cursor should feel responsive and alive.
Empty states and loading states:
Every list that can be empty must have a beautiful empty state — the owl mascot or a subtle branded illustration with a helpful message, not just blank space. Every operation that takes time must show a beautiful loading state — a branded spinner or progress animation, never a frozen UI.
Error states:
Every error must be displayed in a styled, on-brand dialog. Never a raw system error message shown to the user. Errors should be calm, clear, and visually consistent with the rest of the OS.
Consistency sweep:
Go through every single GTK4 app, every EWW widget, every panel, every dialog, every flyout, and verify absolute consistency. Same corner radius everywhere. Same shadow depth everywhere. Same spacing grid everywhere. Same animation timing everywhere. Same hover states everywhere. Same focus states everywhere. If anything looks different from anything else — fix it. The entire OS must feel like it was designed by one person who cared deeply about every pixel.
The standard:
When someone sees NyX for the first time they should stop and stare. It should not look like Linux. It should not look like Windows. It should not look like macOS. It should look like NyX — something they have never seen before. Dark, intelligent, alive, and stunning. Build it to that standard.
Full Build Standard applies. UI and backend together. Nothing stubbed. Nothing placeholder. Verify-profile green before PR. Full changelog and green checklist. If it is not breathtaking it goes back."**
