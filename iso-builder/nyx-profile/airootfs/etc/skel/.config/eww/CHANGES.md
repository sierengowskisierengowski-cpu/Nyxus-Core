# NYXUS bars — signature eye-candy redesign (CHANGES)

Redesign of the existing eww (GTK3 + yuck + SCSS) bars into cohesive,
depth-driven, motion-forward Hyprland eye candy. **No rebuild** — all existing
data sources, scripts, and modules were preserved; only presentation + motion
were added/changed. Bar stays launchable at every step.

Engine: **eww 0.5.0 (GTK3)**. Live config: `~/.config/eww`, synced to
`Nyxus-Core` via `scripts/sync-live-config.sh`.

---

## What changed

### Background / depth
- All four bars use the HOME-page dark-purple ink `rgba(7,5,14,0.97) → rgba(4,2,8,0.96)`
  as the dominant fill so neon pops against it.
- Faint **graffiti ghost** texture (`assets/graffiti-*.png`, generated by
  `scripts/gen-graffiti-assets.py`) sits just above the ink — mostly hidden, lifted
  for a beat as the comet sweeps past.
- Glass capsules: pills, HUD tiles, app-rail icons, and the ticker box share one
  glass treatment (top sheen → deep ink, inset highlight).

### Signature effect (the ONE) — perimeter comet
- A single purple shooting star (white-hot head, violet tail) travels **clockwise
  around the whole screen perimeter**: top → right rail → bottom → left rail → loop.
- Loop logic lives in `scripts/prism-anim.sh` (Python), which streams per-bar head
  positions (`ctop/cright/cbot/cleft`, `-60` = off-canvas) so only one bar is lit at
  a time and the light hands off cleanly at the corners.
- ~13s lap. Tune speed: change `360.0 / 13.0` in `prism-anim.sh`.

### Motion
- **Aurora / prism rim** — `PRISM` deflisten (`prism-anim.sh`) drives animated rim
  angle + breathing glow on every bar.
- **Audio-reactive** — `CAVA` deflisten (`scripts/cava.sh`) feeds the visualizer.
- **Load-reactive glow (new)** — `sys-pulse.sh` emits `hot` (1 when CPU ≥ 90% or
  temp ≥ 97 °C); all four bars flush red while hot, then settle.

### Live HUD monitors (new)
- Bottom-bar center strip now shows `CPU · RAM · GPU · TMP · FAN · NET`, matching the
  home-page HUD. Data from extended `scripts/sys-pulse.sh`:
  - GPU util/temp via `nvidia-smi`
  - fan RPM via `sensors` (lm_sensors)
  - live network rx/tx sampled per poll from `/proc/net/dev`
- Missing hardware degrades gracefully to `--`.

## How to tweak

| Want to change | Where |
|---|---|
| Comet speed | `scripts/prism-anim.sh` → `cang = (t * (360.0 / 13.0))` (raise divisor = slower) |
| Comet color | `eww.yuck` comet layers → the `rgba(150,90,255…)` / `rgba(200,165,255…)` stops |
| Graffiti visibility | `scripts/gen-graffiti-assets.py` → alpha `randint(...)`, then re-run it |
| Load-glow thresholds | `scripts/sys-pulse.sh` → `cpu >= 90` / `temp >= 97` |
| Ink / purple depth | ink stops `rgba(7,5,14,0.97)` in `eww.yuck` + `eww.scss` |
| Bar FX on/off (zero CPU) | `nyxus.conf` → `NYXUS_BAR_FX=off` |
| FX frame rate | `nyxus.conf` → `NYXUS_BAR_FX_FPS` (default 8) |

Accent colors follow `~/.config/nyxus/accent.json` via `nyxus-apply-accent`
(`_nyxus_accent.scss`). Re-run `gen-graffiti-assets.py` after a preset switch to
re-tint the ghost texture.

## Honesty / tradeoffs (eww is GTK3 CSS, 2D)

- **No live 3D / particle physics.** The comet is a moving CSS gradient (bright head +
  tapered tail), not a particle system. A photoreal fiery comet would require a
  pre-rendered looping WebP/APNG sprite (drop-in point: `assets/`, referenced via a
  moving `background-position` layer) — not yet wired.
- **No `clip-path` in GTK3** — non-rectangular "shard" shapes are not possible; bars use
  rounded rectangles.
- **Graffiti "reveal under comet"** is a visual approximation (faint texture + bright
  comet pass), not a true masked spotlight — GTK CSS has no moving mask.

## Dependencies (Arch)

Already required by the existing setup; new work leans on:

```bash
sudo pacman -S --needed eww cava lm_sensors           # bars, audio viz, fan RPM
sudo pacman -S --needed python-pillow                  # graffiti asset generator
# GPU stats: nvidia-utils (NVIDIA) — optional, degrades to -- if absent
sudo pacman -S --needed nvidia-utils
sudo sensors-detect --auto                             # one-time, enables fan RPM
```

## Restore points

Timestamped backups live in `~/.config/eww/.restore-points/`
(`eww.yuck.*`, `eww.scss.*`, `prism-anim.sh.*`, `assets.*`). Restore with:

```bash
cd ~/.config/eww
cp .restore-points/eww.yuck.<STAMP> eww.yuck
cp .restore-points/eww.scss.<STAMP> eww.scss
eww reload
```
