CORE ENGINE — What makes CIPHER genuinely different:
Intelligence Layer 1 — GowskiNet Credential Database:
CIPHER has direct access to every credential ever captured by your Cowrie honeypot. Over 4600+ real attacks worth of real username and password combinations that real attackers actually use. This is intelligence no commercial tool has. CIPHER analyzes these continuously:

Most common passwords tried by real attackers
Most common username patterns
Seasonal trends — do attackers try different passwords at different times
Geographic patterns — do attackers from certain countries prefer certain passwords
Evolution tracking — how attacker credential lists have changed over time
Correlation analysis — which usernames appear with which passwords
Pattern extraction — what rules and mutations attackers apply to base words
This living intelligence feeds directly into wordlist generation and attack strategy

Intelligence Layer 2 — Pattern Learning Engine:
CIPHER studies every password it successfully cracks and learns:

How humans structure passwords — base word + number + symbol patterns
Common substitutions — a→@ e→3 i→1 o→0 s→$ etc and which are most common
Number patterns — most people use birth years, 123, 69, their address
Symbol placement — most people put symbols at the end or after the base word
Length distribution — most passwords cluster at 8-12 characters
Language patterns — which languages, which words, which name types
Cultural patterns — location specific words, local sports teams, local references
Corporate patterns — company name + year + symbol is extremely common
The more passwords CIPHER cracks the smarter it gets

Intelligence Layer 3 — Claude AI Targeting:
When you give CIPHER context about a target — not for attacking others, for testing your own accounts and understanding how targeted attacks work — Claude generates hyper-intelligent wordlists:

You provide: name, location, interests, job, pets, important dates, company
Claude generates: every likely password combination a human with that profile would create
Includes: name variations, important years, pet names + numbers, sports teams, company names, common phrases in their language
Generates passwords the target would actually think of, not random strings
This is exactly what sophisticated human attackers do manually — CIPHER automates it with AI
For understanding how targeted attacks work and hardening your own passwords

Intelligence Layer 4 — Custom Rule Generation:
CIPHER generates custom Hashcat and John rules based on what it has learned:

Analyzes patterns in your cracked password database
Generates rules that match how real humans in your specific dataset mutate passwords
These custom rules outperform generic rulesets because they're based on real data
Rules improve automatically as more passwords are cracked
Export rules for use in GSL or external tools

Intelligence Layer 5 — Hash Intelligence:
CIPHER knows everything about hashes:

Auto-identifies any hash type — MD5, SHA1, SHA256, SHA512, bcrypt, scrypt, Argon2, NTLM, LM, MySQL, PostgreSQL, Django, Laravel, WordPress, every format
Identifies weak hashing — unsalted MD5, deprecated algorithms
Detects hash reuse — same hash appearing multiple times
Estimates crack difficulty before starting — saves time on impossible hashes
Identifies likely source — does this look like a Linux shadow file, Windows SAM, web app database

3. Attack Engine

Where you configure and launch cracking attacks
Job configuration:

Select hashes to attack — from submitted queue
Hash type — auto-detected or manual override
Attack mode selector:



Mode 1 — Dictionary Attack:

Select wordlists from library
Multiple wordlists simultaneously
Rule selection — built in rules + your custom generated rules
Estimated time display before starting
GPU or CPU selection

Mode 2 — AI Targeted Attack:

Input context about the password owner
Name, location, interests, job title, company, pets, important dates, hobbies, favorite sports team, birth year, children names
Claude generates hyper-targeted wordlist in real time
Shows generated wordlist before attacking — you can review and edit
Runs targeted wordlist first then falls back to mutations

Mode 3 — GowskiNet Intelligence Attack:

Uses your honeypot credential database as primary wordlist
Applies learned mutation patterns from your crack history
Uses your custom generated rules
Highest success rate for common passwords because it uses real attacker data

Mode 4 — Pattern Attack:

You define a pattern: [name][year][symbol] or [word][number][word]
CIPHER generates all combinations matching that pattern
Based on what your pattern learning engine has found most common
Useful when you know something about how the password was constructed

Mode 5 — Brute Force:

Charset selection: lowercase, uppercase, numbers, symbols, custom
Length range: min and max
Estimated time and combination count shown before starting
GPU accelerated via Hashcat CUDA
Smart brute force — starts with most likely character combinations based on learned patterns

Mode 6 — Hybrid Attack:

Combines dictionary + brute force
Wordlist words with brute forced prefixes and suffixes
Most effective against password + number combinations

Mode 7 — Fingerprint Attack:

You know something about the password — maybe you saw part of it, maybe you know the policy
Input what you know: starts with capital, ends with number, contains the word "summer", is exactly 10 characters
CIPHER generates only candidates matching those fingerprints
Dramatically reduces search space

Mode 8 — Rainbow Table Attack:

Pre-computed rainbow tables for common unsalted hashes
Instant cracking of MD5, SHA1, NTLM, LM if unsalted
Manage rainbow table library — download, store, index

Mode 9 — Combinator Attack:

Two wordlists combined — every word from list A + every word from list B
Generates compound passwords: word+word, name+place, color+animal
Effective against passphrase style passwords

Mode 10 — PRINCE Attack:

Probability Infinite Chained Elements
Advanced statistical attack based on password probability
More intelligent than pure brute force
Uses your learned pattern statistics to order candidates by likelihood
Launch job button
Estimated time and speed prediction before launching
GPU vs CPU recommendation based on hash type and count
