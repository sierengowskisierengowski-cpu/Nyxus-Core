Project Type
Native desktop application for Linux (Arch/COSMIC primary target). Built using Tauri (Rust backend + React/TypeScript frontend) — produces a real compiled binary, installs natively, real .desktop file, real icon, no browser.
Author
Joseph Sierengowski
Description
Real-time threat intelligence command center for personal honeypot infrastructure. Aggregates and visualizes attack data from multiple honeypot services. Built as a serious threat intel research tool.
Repository
New separate GitHub repo: gowskinet-honeypot-command-center
Stack

Tauri 2.x (Rust backend)
React 18 + TypeScript + Tailwind + shadcn/ui (frontend)
PostgreSQL (persistent storage) with SQLite fallback for local-only mode
Redis for real-time pub/sub
WebSocket for live event streaming
JWT auth with refresh tokens
Tauri's secure storage for credentials

Data Sources (Honeypot Integrations)

Cowrie (SSH/Telnet — ports 2222/23)
Heralding (FTP, SMTP, RDP, VNC)
Dionaea (SMB/SQL — ports 445/1433)
HTTP-Honeypot (custom — port 8888)
Glastopf (web honeypot)
Mailoney (SMTP)

Parser pushes events to local API endpoint /api/events/ingest with bearer token auth.
Severity Classification (All Implemented, No Placeholders)

INFO (green) — scans, single failed logins, probes
LOW (blue) — repeated probes, basic brute force
MEDIUM (yellow) — sustained brute force, credential stuffing, dictionary attacks
HIGH (orange) — successful auth, command execution, downloads
CRITICAL / RED LINE (red, animated siren, sound alert) — malware payload, APT IoC match, RCE, post-exploitation, data exfil

GET /api/ips/:ip — full enriched info on attacker IP

GET /api/honeypots/status — health check on configured sources
OpenAPI/Swagger documentation at /api/docs
