CORE ENGINE — How attacks are generated:
Three generation modes working together:
Mode 1 — Template Primitives Engine:

Library of hundreds of attack building blocks
Reconnaissance primitives: port scan, service detection, OS fingerprint, banner grab, DNS enum, OSINT gather
Access primitives: brute force, credential stuffing, exploit, phishing, evil twin, MITM
Execution primitives: bash oneliner, Python script, compiled binary, macro, shellcode
Persistence primitives: cron job, systemd service, bashrc injection, SUID bit, SSH key plant
Evasion primitives: slow timing, random delays, traffic mimicry, log clearing, process hiding
Exfiltration primitives: DNS tunneling, HTTP POST, ICMP covert channel, steganography
Engine randomly combines valid combinations from each stage
Adds randomized variables — ports, timing, naming, encoding
Produces structurally sound attack chains every time

Mode 2 — Claude AI Generation:

Full Claude API integration with deep cybersecurity system prompt
Knowledge base loaded into context: MITRE ATT&CK all techniques, real malware behavior patterns, living off the land techniques, evasion methods, real CVE exploit patterns, honeypot captured attack data from GowskiNet logs
Claude generates actual working bash/Python attack scripts from scratch
Every generation completely unique — novel combinations never seen before
Can combine techniques across domains — WiFi + social engineering + persistence
Generates realistic attacker naming — fake C2 domains, realistic process names, convincing file paths
Code is real and actually executes

Mode 3 — Hybrid (default):

Template engine provides the attack structure and deployment framework
Claude fills in the novel payload, evasion technique, and specific implementation
Result: structurally reliable attacks with genuinely novel content
Truly unpredictable — even the operator doesn't know exactly what will be generated
