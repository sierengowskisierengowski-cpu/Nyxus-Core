## 5. What the 2026-08-01 pass changed

Full per-defect disposition is in
[`docs/ISO_FULL_AUDIT_2026-07-31.md`](./ISO_FULL_AUDIT_2026-07-31.md) §8.
Summary of the classes:

1. **Boot chain** — no boot path set `cow_spacesize` (the overlay hit 100% four
   minutes into first boot); the BIOS menu had labels but no `UI` directive so
   it drew nothing; the UEFI menu widget never drew because GRUB boxes are
   nine-slice and only three slices shipped.
2. **Permissions** — 116 executables, not the 12 the VM audit found, were
   shipping mode 644 including the ARSENAL and MESH station launchers and
   every eww/hypr script. The array is derived now.
3. **systemd** — the 2-minute stall and all four failing units, four unrelated
   causes.
4. **Greeter** — session list, default account, focus colour, popover theming.
5. **Session start** — the blank Welcome wizard (our own chrome shrank it), the
   riddle with no visible exit, floating windows behind the bottom bar.
6. **First boot** — the live stick was compiling four compositor plugins into
   its own 256 MB overlay.
7. **Palette** — six web surfaces were never on ALIEN NEON, and the icon,
   cursor and wallpaper generators were baking banned colours into shipped
   assets. Now one shared token sheet and a gate.
8. **Deploy paths** — ten symlinks under `nyxus-scripts` pointed at absolute
   paths inside `/home/cosmic`, so they dangled in every other checkout and two
   allowlisted tools (`nyxus-boot-check`, `nyxus-persist-login`) deployed as
   dead links. The two installer allowlists had also drifted apart in both
   directions, so the dev path and the ISO path produced different systems.
9. **Application menu** — twelve apps were listed twice, once with a real icon
   and once with the generator's placeholder.
10. **Dead keys** — `Super+F3` / `Super+Alt+A` / four-finger-up dispatched
    `hyprexpo:expo`, a plugin that is never loaded on live media and usually
    absent elsewhere, and did nothing silently. They fall back to the native
    `nyxus-mission` overview, which was already shipping and autostarted.
11. **Decoys deleted** — `nyx-profile/efiboot/` (never shipped),
    `artifacts/nyxus-home/config/hyprland.conf` (never staged),
    `nyxus-scripts/boot-splash/` (never referenced, gold-era palette),
    `artifacts/nyxus-config/accent-baseline/` (a committed per-machine cache).

**Eight new gates** so these classes cannot return quietly: 13pc
(file_permissions covers every executable), 13pd (`cow_spacesize` + a BIOS
`UI` directive), 13pe (GRUB nine-slice completeness), 13pf (no FORBIDDEN
palette colour in a shipped surface), 13pg (both installer allowlists agree,
every entry resolves, no dangling symlinks), 13ph (no duplicate
application-menu entry), plus the widened 13ak (exactly two copies of
`hyprland.conf`).

### Known dead code, left alone deliberately

Not defects a user can reach, but worth knowing before someone "fixes" them:

- `(defwindow cheatsheet)` in `eww.yuck` is orphaned — every bind opens
  `hotkey-cheatsheet`. Same for `hotkey-recorder` and `quicksettings-daemon`,
  which are defined and never opened.
- `eww close screensaver` appears in `hypridle.conf` and
  `starfield-lock-reveal.sh` for a window that no longer exists; the GTK
  `nyxus_screensaver.py` replaced it. `hypridle.conf` already labels it a
  legacy no-op safety net.
- Several `.desktop` entries are debug tools rather than apps (Toast is a
  "notification debug tester", Splash is a "boot splash preview", Chrome
  Library is a "UI chrome reference"). They run; whether they belong in a
  shipped menu is a product call, not an audit finding.

## 6. ⛔ The deadline nobody has scheduled: Hyprland 0.57 removes `.conf`

The `.conf` deprecation banner (SS-04) has **no opt-out** — it was added in
hyprwm/Hyprland#15538 and shipped in 0.56.1 deliberately without one. The only
way to clear it is to migrate to the Lua config API.

**0.57 removes `.conf` support entirely.** NYXUS has 157 binds across a dozen
sourced shards, plus every windowrule, layerrule, workspace and env line, all
in `.conf`. A bake that picks up 0.57 produces an image whose whole
configuration layer is ignored.

This is the largest forward risk in the build and it is not covered by any
gate, because no gate can see a future package version. It is scoped,
mechanical work with a starting tool (`hyprmorph`), but it needs a live
session to verify against. It should be planned before 0.57 reaches `extra`.
